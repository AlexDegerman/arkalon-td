# Arkalon TD

📋 Planned for a future Arkalon release

A browser-based tower defense game with self-contained stages that take 1 to 3 minutes to complete. It favors positioning, path management, and tower synergy over grinding upgrades or memorizing massive rosters.

The game will utilize [Arkalon Engine](https://github.com/AlexDegerman/arkalon-engine) to present its gameplay within a 2.5D world.
